# LaTeX Manuscript Directory

This directory contains the complete, modular LaTeX source files and compiled publication PDFs for the scientific manuscript:
**"A Fractional Stochastic Transportation Model with Caputo Memory, Demand Uncertainty, and Carbon Trading"**

## Directory Structure

- `main.tex`: Master LaTeX document assembling all sections, appendices, and bibliography.
- `sections/`: Modular LaTeX source files for all main paper chapters (abstract, introduction, literature review, preliminaries, formulation, theoretical properties, progressive hedging algorithm, computational experiments, discussion, conclusion).
- `appendices/`: Modular LaTeX source files for technical appendices (summary of mathematical notation, scenario generation algorithms, formal proofs of theorems, calibration details).
- `generated/`: Output tables (`table_*.tex`) and high-resolution plots (`fig_*.png`) generated by the experimental protocols in `experiments/` and `scripts/`.
- `references.bib`: BibTeX bibliography database containing all literature citations.
- `main.pdf`: Compiled 38-page publication manuscript.
- `fractional_transport_manuscript_39pages.pdf`: Archival benchmark compiled manuscript.

## Compilation

To compile the manuscript from source using pdfLaTeX and BibTeX:

```bash
cd manuscript/
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
